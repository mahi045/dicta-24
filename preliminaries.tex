\subsection*{Fuzzy Image Processing}
Fuzzy logic is used to bridge mathematical operations with linguistic rules \cite{sancho1999methods,singpurwalla2004membership}. As linguistic rule means there are imprecise definitions and subjectivity, the concept of a fuzzy set is used to define the entity on which the operation will be applied. Modeling impreciseness helps us to incorporate subjectivity and expert knowledge \cite{singpurwalla2004membership}. Application of fuzzy logic makes sense in image enhancement as image quality is an imprecise and subjective idea \cite{tizhoosh1998fuzzy,chacon2006fuzzy}.

Fuzzy image processing encompasses a range of techniques designed to understand, represent, and process images, along with their segments and features, as {\em fuzzy sets} (see Figure \ref{fig:fii}). The process begins with the {\em fuzzification} (or encoding) of image data, followed by the {\em defuzzification} (or decoding) of the results. These steps enable the application of fuzzy techniques to image processing. At the core of fuzzy image processing lies in {\em membership modification}~\cite{haussecker2000fuzzy}. The workflow of fuzzy image processing is illustrated in~\Cref{fig:fii}.

\subsection*{Fuzzy Sets for Intensity Transformation}
Image contrast indicates the variation of intensity in an image \cite{guojin2007study,pratt2007digital,gonzalez2008digital}. Higher contrast means higher variation. Contrast enhancement is one of the principal
applications of intensity transformations. From this definition we can see by making dark regions darker and bright regions brighter we can increase the contrast. This idea of enhancing the contrast can be stated using the following rules \cite{gonzalez2008digital} for a gray-scale image :
\begin{itemize}
    \item IF a pixel is \textbf{dark}, THEN make it \textbf{darker}
    \item IF a pixel is \textbf{gray}, THEN make it \textbf{gray}
    \item IF a pixel is \textbf{bright}, THEN make it \textbf{brighter}
\end{itemize}

The concepts of \textbf{dark}, \textbf{gray}, and \textbf{bright} are inherently imprecise. To address this, we need to define what constitutes a \textbf{dark}, \textbf{gray}, or \textbf{bright} pixel. Each pixel is a member of a fuzzy set, and its degree of membership is determined by a membership function. Figure \ref{fig:fuzzy_function} 
illustrates the membership functions for the fuzzy sets as described in~\cite{gonzalez2008digital}. The dark and bright sets are clearly defined for very low and high-intensity values, respectively ($z$-axis). However, in the middle range of $z$, the definitions become less precise. The membership value for a specific $z$ value is obtained from the $y$-axis, which ranges from $0$ to $1$, where $0$ indicates no membership and $1$ indicates complete membership. 
% For any given $z$ value, the sum of all membership values is $1$.

Defuzzification refers to converting the fuzzy value to a {\em single crisp} value. For any given input pixel $z_0$, the output crisp value $v_0$ will be as follows.
\begin{equation} \label{eqn:defuzzy}
v_0 = \frac{\sum\limits_{i=1}^n\mu_{i}(z_0) * v}{\sum\limits_{i=1}^n\mu_{i}(z_0)};n=3
\end{equation}
\begin{description}
    \item[$\mu_{i}(z_0) = $] \quad fuzzy level of the image pixel with value $z_0$
    \item[$v =$] constant/mutable value used in the defuzzification 
\end{description}
\subsection*{Color Information in Image}
\label{subsection:hsv_color}

The color information of an image represents what color will be perceived by viewers. A commonly used color representation is RGB (Red-Green-Blue) where each pixel has three values. Each value indicates the intensity of three color channels Red, Green, and Blue. Typically $8$ bit is used for each channel, which means the value of $[0-255]$ is used to represent the intensity. The overall color is the combination of the intensity of these three channels. This color model is suitable for color representation in display devices. As display devices generate each three colors independently and their combination gives us different color perceptions.

Another way to model color is HSV (Hue-Saturation-Value). HSV also uses three values for each pixel. The Hue channel is used to represent only the dominant wavelength (not its intensity or how pure it is). Saturation indicates how pure it is. For example, the pink color in the HSV model is a red hue but not pure red. It has a mix of other wavelengths hence the whiter look. A complete Saturation value means only the Hue-represented wavelength is giving the perception \cite{vadivel2005human}. The value channel indicates the intensity \cite{shuhua2010application,sural2002segmentation}. A red hue can be perceived as black as if it has zero intensity. In OpenCV implementation of HSV color space, the range of Hue channel is $[0-179]$, Saturation and Value have range of $[0-255]$ \cite{opencvHSV}. Another thing to notice is that in HSV, we separate intensity information from color information \cite{loesdau2014hue}.
